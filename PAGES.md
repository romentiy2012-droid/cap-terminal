# GitHub Pages

Settings → Pages → Deploy from a branch → main → /docs → Save.

Публикуемые файлы находятся в docs/. При изменении dist/ обновлять соответствующие файлы docs/. При изменениях кешируемых файлов повышать CACHE в обоих sw.js. Файлы не требуют компиляции. Включение Pages требует настройки репозитория, одного коммита недостаточно.
