# КЭП — Полевой терминал

Статическая PWA на HTML/CSS/JavaScript. Квесты с опытом, уровни, заметки, экспорт/импорт JSON, отключаемый CRT-эффект. Данные хранятся в localStorage на устройстве. Облачной синхронизации нет.

## Развёртывание
Содержимое dist разместить на HTTPS-хостинге. Все пути относительные, подходят для GitHub Pages в подкаталоге. Сборка и зависимости не нужны. Sites использует .openai/hosting.json.

## Обновление
Править dist, проверить `node --check dist/app.js` и `node --check dist/sw.js`. При изменении ассетов увеличивать версию CACHE в sw.js. После публикации закрыть все окна приложения и открыть заново, чтобы обновлённый service worker активировался. Не менять ключ cap-terminal-v1 без миграции данных.

## Проверки 2026-10-26
Синтаксис JS проверен. В Chrome проверены создание квеста, начисление 25 XP и сохранение после перезагрузки. Визуально проверен десктопный экран. На физическом iPhone, офлайн в Safari и установка на домашний экран ещё не проверены. Manifest, иконки 192/512, service worker включены. Приватный хостинг может требовать онлайн-вход.

## iPhone
Safari → Поделиться → На экран Домой. Данные разных браузеров и установленной PWA могут отличаться; переносить через резервную копию. Очистка данных браузера может удалить записи.
